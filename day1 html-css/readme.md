# Simple Personal Profile Webpage

A beginner-friendly personal profile webpage built using only HTML5 and CSS3.

## 📋 Project Overview

This is a simple, static personal profile webpage demonstrating basic HTML and CSS concepts. The project is designed for beginners learning web development fundamentals.

## ✨ Features

- **Clean & Simple Design** - White cards on light gray background
- **Responsive Layout** - Works on desktop, tablet, and mobile devices
- **Semantic HTML5** - Proper use of HTML5 semantic tags
- **Flexbox Layout** - Modern CSS Flexbox for responsive design
- **No Dependencies** - Pure HTML and CSS, no frameworks or libraries
- **Beginner-Friendly** - Well-commented code, easy to understand

## 🎯 Design Principles

### Colors
- **Primary Color**: Blue (#007bff)
- **Background**: Light Gray (#f4f4f4)
- **Cards**: White (#ffffff)
- **Text**: Dark Gray (#333)
- **Footer**: Dark (#333)

### Layout
- **Container**: Max-width 1100px, centered
- **Cards**: White background, rounded corners (8px), subtle shadow

## 📝 Customization Guide

### Changing Colors

In `style.css`, modify the color values:

```css
/* Change the primary blue color */
.header {
    background-color: #007bff;  /* Change this */
}

.section-title {
    color: #007bff;  /* And this */
}
```

### Changing Content

In `index.html`, update the text within the HTML tags:
- Update name in `<h1>` tag
- Update role in `<p class="role">` tag
- Modify skills, education, and contact information

### Adjusting Layout

In `style.css`, modify the container width or card spacing:

```css
.container {
    max-width: 1100px;  /* Adjust width */
}

.skills-grid {
    gap: 20px;  /* Adjust spacing */
}
```
